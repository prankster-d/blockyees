# Структура проекта

Нативное приложение использует SwiftUI для экранов и UIKit для многослойного холста. `project.yml` генерирует Xcode-проект через XcodeGen. `Package.swift` позволяет отдельно запускать тесты моделей и локального хранения.

| Путь | Назначение |
|---|---|
| `app/Blockyees/App/` | Точка входа, композиция зависимостей и жизненный цикл приложения. |
| `app/Blockyees/Features/Library/` | Библиотека, папки, создание и перемещение файлов. |
| `app/Blockyees/Features/Notebook/` | Обзор страниц, сортировка и навигация по блокноту. |
| `app/Blockyees/Features/Editor/` | Холст, инструменты, слои, преобразования и ввод. |
| `app/Blockyees/Domain/` | Модели и правила работы с блокнотами, страницами и папками. |
| `app/Blockyees/Infrastructure/Persistence/` | Хранение, восстановление и миграции данных. |
| `app/Blockyees/Infrastructure/Sync/` | Синхронизация, очередь изменений и конфликты. |
| `app/Blockyees/Infrastructure/ImportExport/` | Чтение и запись поддерживаемых форматов. |
| `app/Blockyees/Resources/` | Ресурсы приложения и локализация. |
| `tests/Unit/` | Проверки правил сортировки и моделей. |
| `tests/Integration/` | Проверки хранения, импорта и синхронизации. |
| `tests/UI/` | Проверки сценариев интерфейса. |
| `tests/Fixtures/` | Синтетические тестовые документы. |
| `config/` | Общие конфигурации сборки без секретов. |
| `scripts/` | Скрипты сборки и проверки. |
| `docs/` | Требования и техническая документация. |

Команды сборки приведены в README. Подписи, ключи, локальные настройки и пользовательские документы не входят в исходный код.
