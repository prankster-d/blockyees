# Документы и синхронизация

`.blockyees` — JSON-документ версии 1. Документ содержит страницы, слои, штрихи, изображения, стабильные идентификаторы, основной порядок, даты изменений и сведения о ревизиях. Двоичные изображения кодируются Base64. Файл ограничен 100 МБ; неподдерживаемая версия и некорректная геометрия отклоняются без изменения исходника.

Импорт `.blockyees` создаёт независимый документ со слоями и штрихами. Импорт PNG/JPEG и PDF создаёт изображения на слоях: он не восстанавливает векторные объекты и слои из PDF. Другие редактируемые форматы пока не поддерживаются.

Локальные файлы сохраняются атомарно в Application Support. Ошибка чтения одного документа не мешает открыть остальные; повреждённый файл остаётся на месте. При ошибке записи приложение сообщает об этом и позволяет повторить сохранение в настройках.

Режим недавних страниц использует время последнего изменения содержимого. Просмотр, перемещение блокнота и переключение порядка это время не меняют. Экспорт PDF следует видимому порядку страниц; редактируемый экспорт сохраняет основной порядок и выбранный режим. Соседние страницы для onion skin определяются текущим порядком обзора.

iCloud Drive включается в настройках. Локальная работа доступна без сети. Синхронизация запускается после изменений, при активации приложения и вручную. Для подписанной сборки требуется включённая capability iCloud Documents и контейнер, соответствующий `project.yml`.

Ревизии сравниваются по предкам. Последовательная правка заменяет предка. При независимых правках создаётся отдельный блокнот с пометкой «конфликт», сохраняющий вторую версию. Удаление представлено маркером, чтобы оно распространялось на другие устройства. Системные конфликтные версии iCloud сохраняются как дополнительный источник восстановления. Полноценная проверка обмена между двумя физическими устройствами ещё необходима.

Пределы размеров и список поддерживаемых устройств будут уточняться по измерениям. Функциональность нажима доступна лишь на стилусах, передающих его; обычные ёмкостные стилусы используют режим ввода пальцем.
