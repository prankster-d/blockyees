# Правила работы над Blockyees

- Весь проект вести в этом репозитории. Основные требования: `docs/SPEC.md`.
- Целевая платформа — iPad. Не подменять результат приложением для Mac или веб-прототипом.
- Сохранять весь согласованный набор инструментов редактора; не упрощать его без прямого решения пользователя.
- Сортировка «Более поздние страницы вверху» дополняет исходный порядок. В дополнительном режиме правка страницы поднимает её наверх; сортировать по последнему изменению содержимого. Не подменять сортировку перетаскиванием.
- Отделять подтверждённые требования от допущений. Не объявлять поведение проверенным без фактической проверки.
- Коммитить только относящиеся к задаче файлы. Author и committer name для AI-коммитов: `taliya_codex`; существующие Git email и авторизацию пользователя сохранять.
- После подходящей проверки изменений выполнить commit и push в согласованную ветку и проверить удалённый SHA. Не использовать force push без явного разрешения.
