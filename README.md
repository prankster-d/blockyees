# Blockyees

Графический блокнот для iPad с редактируемыми страницами, папками и синхронизацией.

## Возможности текущей разработки

- Рисование, слои, выделение и преобразования, изображения, undo/redo.
- Два порядка страниц: основной и по последнему изменению, новые правки сверху.
- Папки и перемещение блокнотов между ними.
- Импорт существующих редактируемых блокнотов.
- Синхронизация между устройствами.
- Сенсорный ввод и поддержка совместимых стилусов.

## Состояние проекта

Исходный код нативного приложения для iPadOS 17+ находится в репозитории. Проверка сборки и тесты выполняются в GitHub Actions. Публичная устанавливаемая версия пока не выпущена.

Редактируемый импорт поддерживает формат `.blockyees`. PDF и изображения импортируются как изображения страниц; импорт других форматов редактируемых блокнотов ещё не реализован.

Для работы iCloud требуется подписанная сборка с настроенным контейнером. Синхронизация на физических устройствах ещё не проверена.

## Сборка

На macOS с Xcode и XcodeGen:

```sh
swift test
xcodegen generate
open Blockyees.xcodeproj
```

Для сборки без подписи выбери iPad Simulator. Для устройства укажи команду разработки и настрой идентификаторы приложения и iCloud в `project.yml`. Секреты в репозиторий не добавляются.
