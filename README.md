# Blockyees

Графический блокнот для iPad с редактируемыми страницами, папками и синхронизацией.

## Планируемые возможности

- Рисование, слои, выделение и преобразования, изображения, undo/redo.
- Два порядка страниц: основной и по последнему изменению, новые правки сверху.
- Папки и перемещение блокнотов между ними.
- Импорт существующих редактируемых блокнотов.
- Синхронизация между устройствами.
- Сенсорный ввод и поддержка совместимых стилусов.

## Состояние проекта

Подготовлены требования и структура каталогов. Реализация, собираемый проект и доступная для установки версия пока отсутствуют.
